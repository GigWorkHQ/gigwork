# Assets and provenance

The public runtime uses local artwork and fonts. It does not load Jasper tracking, lead forms, third-party chat, Rive runtime or external media.

- Mascots: generated for this task using OpenAI ImageGen. Final selected files are `gigwork-owl.png`, `gigwork-fox-v2.png`, and `gigwork-robot.png`. Prompts and original generation paths are recorded in ASSET-PROMPTS.md for provenance only; those paths are not runtime dependencies. The original fox draft is retained as an unused iteration.
- Gigwork logo/banner/favicon: editable native SVG composition, generated by `scripts/create_brand.py`. The wordmark is outlined from the reference typeface. Mascot pixels remain unchanged in the banner.
- Feature Headline, ABC ROM and ABC ROM Mono: source font binaries retrieved from the supplied Jasper reference for visual fidelity. No redistribution or production webfont license was supplied or verified. Confirm rights with the typeface owners before independent commercial distribution; keep font licensing separate from source-code ownership. The private reference baseline retains third-party imagery and marks solely for comparison.
- Lucide icons: lucide-react, ISC license. React: MIT license. Vite: MIT license. Keep their package license notices when distributing dependency source.
- Supplied PDFs, video and dashboard reference remain user source materials. The delivery includes the PDFs privately and the baseline comparison; these are outside `public` and `dist`.

No claim is made that a 1:1 layout request transfers ownership of the reference's original assets. Gigwork's production font license remains unresolved.

Marketplace art: seven original SVG compositions generated by scripts/create_marketplace_art.mjs. They use fixed vector shapes, text and embedded unchanged Gigwork owl/robot artwork from the approved generated set. Covers represent the actual six task briefs. Editable source is included; no third-party marketplace photos or ratings are used.

Dependency license texts from the installed, locked packages are copied into docs/licenses with an index. The complete developer archive includes source reference materials separately from the app; only public/dist assets are part of the website runtime.
